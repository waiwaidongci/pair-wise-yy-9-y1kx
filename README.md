# 古法蓝晒底片整理室

运行：

```bash
npm start
```

访问`http://localhost:3040`。数据保存在`data/cyanotype-negative-room.json`。

测试：

```bash
npm test
```

## 分层

- `server.js` —— 接线层，只做 HTTP 路由。
- `src/page.js` —— 页面层，展示批谱、待核读数、判定与重算结果。
- `src/judgment.js` —— 判定层，纯函数的账本规则。
- `src/archive.js` —— 存档层，原子落盘、串行变更、按现场单号重放。

## 批谱流程

回收液登记（来源、实测浓度、重量）→ 再配开缸（抽液即扣来源余量，配制中不计入可用量）→ 倒缸确认（才计入可用量）→ 玻璃板冲洗结论与入盒许可。

- 同一回流单先写入的读数生效，后到值留待核；采纳后替换生效值并重算，驳回不动账。
- 批次浓度或配比一改，按它做出的冲洗结论与入盒许可立即失效重算，旧履历留在批次履历里可追查。
- 每个写操作带现场单号（requestId）：写盘失败后按同一单号重试，从已确认的倒缸步骤接着办，液量不会重复扣。
